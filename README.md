## 📂 Featured Projects

### Machine Learning

- **[HR Analytics – Employee Attrition Prediction System](https://github.com/DharshanaGit/Employee_retention)**
  
 Developed a machine learning solution to identify employees at risk of attrition using HR analytics data. Applied preprocessing, feature engineering,
 cross-validation,and model optimization techniques, achieving over 80% prediction accuracy and deploying the application using Streamlit.

- **[Student Score Prediction – Linear Regression](https://github.com/DharshanaGit/StudentScore_LinearReg)**
  
  A supervised machine learning project using **Linear Regression** to predict student performance based on academic and behavioral factors.  
  Includes data preprocessing, feature selection, model training, evaluation metrics, and result interpretation.

- **[Pet Adoption Prediction App – Decision Tree](https://github.com/DharshanaGit/Pet_adopt_Decisiontree)**
  
  A **Decision Tree–based classification application** designed to predict the likelihood of pet adoption.
